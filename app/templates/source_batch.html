查看 YAML 字段说明
name
页面显示名称。
kind
x_rsshub、reddit、youtube 或 rss。
locator
X 填 @账号，Reddit 填 r/社区，YouTube 填 @频道 或频道地址，RSS 填订阅地址。
description
可选的一句话账号简介；当同平台、同地址的来源已存在时，非空简介会更新到该来源，其余配置不变。
official / enabled / archived
可在 defaults 中统一设置，也可在单条来源中覆盖；来源导出文件会保留暂停和归档状态，抓取间隔统一在“设置与连接”中管理。
